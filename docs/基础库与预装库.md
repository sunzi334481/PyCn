# 基础库与预装库手册

本手册列出 PyCn（中文 Python）的全部语言内置（基础库）与预装标准库 API。
内容由 `tools/gen_api_docs.py` 依据 `pycn_lang/mappings.py` 自动生成，
与实现保持完全一致。

> 说明：本文「中文 → Python」映射是 **逐词替换** 的静态映射：
> 转译时先判关键字，再判属性位置（点号后），再判全局名字；
> 用户自定义的中文标识符一律原样保留，绝不会被映射误伤。
