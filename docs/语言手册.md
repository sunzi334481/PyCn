# PyCn 语言手册

PyCn（Python 中文版 / Chinese Python）是一门**全中文语法**的编程语言：所有非用户自定义的语法都是中文，源码文件后缀为 `.pycn`。它由 Python 3 驱动——源码会被逐词转译为标准 Python 后执行，因此你写的每一个中文语法都有确定的 Python 对应物，行为与 Python 完全一致。

本手册是语言的完整语法说明。基础库与预装库的 API 清单见《基础库与预装库.md》。

---

## 1. 快速上手

```pycn
# 冒烟测试：覆盖主要语法
分数列表 = [88, 76, 92, 65, 100]
打印("人数：", 长度(分数列表))
打印("最高分：", 最大值(分数列表))

定义 阶乘(数):
    如果 数 <= 1:
        返回 1
    返回 数 * 阶乘(数 - 1)

打印("5 的阶乘：", 阶乘(5))

类 学生:
    定义 __初始化__(自己, 名字, 分数):
        自己.名字 = 名字
        自己.分数 = 分数
    定义 是否及格(自己):
        返回 自己.分数 >= 60

小明 = 学生("小明", 92)
打印(小明.名字, "及格吗？", 小明.是否及格())
```

运行：

```bash
python -m pycn_lang run 冒烟测试.pycn
```

输出：

```
人数： 5
最高分： 100
5 的阶乘： 120
小明 及格吗？ True
```

## 2. 运行方式

### 2.1 命令行（CLI）

| 命令 | 作用 |
| --- | --- |
| `python -m pycn_lang run 脚本.pycn [参数...]` | 运行 .pycn 程序 |
| `python -m pycn_lang 脚本.pycn [参数...]` | `run` 的简写 |
| `python -m pycn_lang compile 脚本.pycn [-o 输出.py]` | 把 .pycn 转译为标准 Python（默认生成同名 .py；`-o -` 输出到标准输出） |
| `python -m pycn_lang repl` | 启动中文交互式环境（REPL） |
| `python -m pycn_lang version` | 显示版本 |

安装后可全局使用 `pycn` 命令（见顶层 README「安装」一节）；若 `pycn.exe` 不在 PATH 中，统一用 `python -m pycn_lang`。

### 2.2 编辑器内直接运行

- **VSCode**：安装 `pycn-vscode.vsix` 后，打开 `.pycn` 文件，点编辑器右上角的「▶」按钮（或右键 → 运行 PyCn、快捷键 `Ctrl+Alt+N`）即可运行，输出显示在终端。
- **JetBrains IDE**：安装插件后，`.pycn` 文件有语法高亮，右键/运行配置可一键运行（需要 JDK 17 构建插件）。
- **Visual Studio**：安装插件后，`.pycn` 文件有语法高亮，编辑器顶部有「▶ 运行 PyCn」按钮。

### 2.3 导入 .pycn 模块

PyCn 自带 import 钩子：**你的 `.pycn` 文件可以被其它 `.pycn` 文件（以及 Python）当作普通模块导入**。钩子安装后，`.pycn` 后缀会被注册到 Python 的导入机制中，模块名与文件名一致即可。

```pycn
# 模块演示_工具.pycn
定义 加(甲, 乙):
    返回 甲 + 乙
```

```pycn
# 模块演示_主.pycn
从 模块演示_工具 导入 加
打印(加(1, 2))   # 3
```

## 3. 词法规则

### 3.1 缩进与换行

与 Python 完全一致：**缩进决定代码块**，每个缩进层级为 4 个空格（或 Tab，需与 Python 一致——建议统一用 4 空格）。转译过程不增删换行，报错行号与源码一一对应。

### 3.2 注释

```pycn
# 这是注释（与 Python 相同）
```

注释原样保留，不参与翻译。

### 3.3 标识符

Python 3 原生支持 Unicode 标识符，因此**用户自定义的中文变量名、函数名、类名、参数名原样保留**，不会被映射误伤：

```pycn
苹果数量 = 5
香蕉 = 3
定义 计算总和(甲, 乙):
    返回 甲 + 乙
```

标识符也可以混用中英文：`第1项`、`总金额`、`my_变量` 均合法。命名规则与 Python 相同：首字符为字母或 `_`，后续可为字母、数字、`_`。

### 3.4 字符串与前缀

字符串字面量与 Python 相同，支持单引号、双引号、三引号；额外支持**中文前缀**：

| 前缀 | 含义 | Python 对应 |
| --- | --- | --- |
| `格"..."` | 格式化字符串（f-string） | `f"..."` |
| `原"..."` | 原始字符串 | `r"..."` |
| `字"..."` | 字节串 | `b"..."` |

可以组合：`格原"..."` → `fr"..."`。

f-string 内部的中文表达式也会被转译：

```pycn
定义 阶乘(数):
    返回 1 如果 数 <= 1 否则 数 * 阶乘(数 - 1)

名字 = "小明"
打印(格"你好，{名字}！")              # 你好，小明！
打印(格"阶乘：{阶乘(5):>6}")        # 支持格式说明符
打印(格"原样：{名字!表示}")          # !表示 → !r，等价于 repr
```

f-string 转换标志：`!表示`→`!r`、`!字符串`→`!s`、`!码`→`!a`。

特殊字符串：字面量 `"__主__"` 会自动转换为 `"__main__"`，用于主程序判断：

```pycn
如果 __名字__ == "__主__":
    打印("这是主程序")
```

### 3.5 数字

数字字面量与 Python 完全相同，支持十进制、浮点、指数、十六进制、二进制、八进制、虚数后缀：

```pycn
数 = 42
浮点数 = 3.14
科学计数 = 1e6
十六进制数 = 0xFF
复数 = 2 + 3j
```

### 3.6 运算符

除关键字映射外，运算符保持 Python 原样（`+ - * / // % ** == != < > <= >= & | ^ ~ << >> = += -= ...`）。唯一的例外是三个复合关键字：`在`、`不在`、`不是`（见关键字表）。

## 4. 关键字（39 个）

下表是语言的骨架，**优先级最高**——即使名字出现在属性位置，也会先按关键字处理。

| 中文 | Python | 用途 |
| --- | --- | --- |
| `假` / `真` / `空` | `False` / `True` / `None` | 布尔与空值 |
| `且` / `或` / `非` | `and` / `or` / `not` | 逻辑运算 |
| `在` / `不在` / `是` / `不是` | `in` / `not in` / `is` / `is not` | 成员与身份判断 |
| `如果` / `否则若` / `否则` | `if` / `elif` / `else` | 条件分支 |
| `对于` ... `在` ... | `for` ... `in` ... | 循环（可配 `否则` 作循环 else） |
| `当` | `while` | 条件循环 |
| `跳出` / `继续` | `break` / `continue` | 循环控制 |
| `定义` / `返回` / `生成` | `def` / `return` / `yield` | 函数定义 |
| `来自` | `from`（`yield from`） | 生成器委托 |
| `匿名` | `lambda` | 匿名函数 |
| `类` | `class` | 类定义 |
| `尝试` / `捕获` / `最终` | `try` / `except` / `finally` | 异常处理 |
| `抛出` | `raise` | 抛出异常 |
| `导入` / `从` / `作为` | `import` / `from` / `as` | 导入 |
| `伴随` | `with` | 上下文管理器 |
| `断言` | `assert` | 断言 |
| `删除` | `del` | 删除 |
| `全局` / `非局部` | `global` / `nonlocal` | 作用域声明 |
| `异步` / `等待` | `async` / `await` | 异步编程 |
| `跳过` | `pass` | 空语句占位 |
| `匹配` / `情形` | `match` / `case` | 模式匹配 |

> 注意：`从` 在 `从 ... 导入 ...` 中表示 `from`；`来自` 专用于 `yield from`。

### 4.1 条件分支

```pycn
如果 分数 >= 90:
    打印("优秀")
否则若 分数 >= 60:
    打印("及格")
否则:
    打印("不及格")
```

### 4.2 循环

```pycn
对于 数字 在 范围(1, 6):
    如果 数字 == 3:
        继续          # 跳过 3
    如果 数字 == 5:
        跳出          # 到 5 结束
    打印(数字)
```

```pycn
计数 = 0
当 计数 < 3:
    计数 += 1
    打印(计数)
```

### 4.3 函数

```pycn
定义 求和(甲, 乙=0):
    返回 甲 + 乙

定义 生成偶数(上限):
    对于 数 在 范围(上限):
        如果 数 % 2 == 0:
            生成 数     # 生成器
```

关键字参数的名字也支持中文（调用时）：

```pycn
定义 描述(名字, 年龄=18):
    返回 格"{名字}今年{年龄}岁"

打印(描述(名字="小明", 年龄=13))
```

注意：标准库关键字参数名优先按库 API 映射翻译（如 `键=`→`key=`、`倒序=`→`reverse=`、`确保ASCII=`→`ensure_ascii=`、`缩进=`→`indent=`），以便与 Python 标准库无缝对接：

```pycn
导入 序列化
打印(序列化.转文本({"a": 1}, 确保ASCII=假, 缩进=2))
```

### 4.4 类与面向对象

```pycn
类 动物:
    定义 __初始化__(自己, 名字):
        自己.名字 = 名字
    定义 叫声(自己):
        跳过            # 抽象占位
    定义 __字符串__(自己):
        返回 格"动物({自己.名字})"

类 狗(动物):
    定义 叫声(自己):
        打印("汪汪！")

旺财 = 狗("旺财")
旺财.叫声()
```

魔术方法（dunder）全部有中文名：`__初始化__`（`__init__`）、`__字符串__`（`__str__`）、`__加__`（`__add__`）、`__长度__`（`__len__`）、`__迭代__`（`__iter__`）……完整清单见《基础库与预装库.md》第 5 节。

### 4.5 异常处理

```pycn
尝试:
    结果 = 1 / 0
捕获 零除错误 作为 错误:
    打印("捕获到异常：", 错误)
捕获 (值错误, 类型错误):
    打印("值或类型错误")
最终:
    打印("最终块一定会执行")
```

### 4.6 模式匹配（match/case）

```pycn
匹配 命令:
    情形 "运行":
        打印("开始运行")
    情形 "停止":
        打印("停止")
    情形 _:
        打印("未知命令")
```

### 4.7 异步

```pycn
导入 异步库

异步 定义 取数据(标识):
    等待 异步库.异步睡眠(1)
    返回 标识

打印(异步库.运行异步(取数据(42)))   # 42
```

### 4.8 上下文管理器

```pycn
伴随 打开("笔记.txt", "w") 作为 文件:
    文件.写入("你好")
```

### 4.9 其他语句

```pycn
断言 长度(列表) > 0          # assert
删除 列表[0]                 # del
全局 计数器                  # global
匿名函数 = 匿名 甲: 甲 * 2   # lambda
```

## 5. 导入（import）

PyCn 对 import 语句做**整句特殊解析**，并自动补上中文别名绑定。

### 5.1 导入模块

```pycn
导入 数学              # → import math as 数学
```

此后用 `数学.平方根(...)` 调用。多模块：

```pycn
导入 数学, 随机        # → import math as 数学, random as 随机
```

### 5.2 从模块导入名字

```pycn
从 日期时间 导入 日期时间类
# → from datetime import datetime as 日期时间类
```

多个名字、别名、通配符都支持：

```pycn
从 数学 导入 平方根, 圆周率
从 数学 导入 对数 作为 取对数     # 别名
从 数学 导入 *                    # 通配
```

### 5.3 相对导入与跨行

支持相对导入（`从 .导入 工具`）、括号跨行与反斜杠续行：

```pycn
从 .工具 导入 处理
从 数学 导入 (
    平方根,
    阶乘,
)
```

### 5.4 模块名解析规则

1. 整段模块名先查中文模块表（`数学`→`math`、`日期时间`→`datetime`、`并发期货`→`concurrent.futures`……）；
2. 未命中则逐段查（如 `操作系统.路径` → `os.path`）；
3. 仍未命中则视为**用户自己的 .pycn 模块**，原样保留模块名交给 import 钩子加载。

完整模块表见《基础库与预装库.md》第 6 节。

## 7. 转译原理（进阶）

PyCn 采用**token 级转译**：

1. 手写扫描器把源码切分为 注释 / 字符串 / 名字 / 数字 / 运算符；
2. 每个名字按优先级查表：**关键字 → 属性位置表 → 全局名字表**，未命中则原样保留（用户标识符）；
3. 不增删换行，因此报错行号与源码一致；traceback 通过 linecache 直接显示 `.pycn` 中文源码行；
4. `compile` + `exec` 执行，与 Python 完全同语义。

```bash
# 查看转译结果
python -m pycn_lang compile 示例.pycn -o -
```

这也意味着：**任何 Python 代码都能改写为 PyCn，任何 PyCn 代码都能转回可读的 Python**——学习成本趋近于零，且天然兼容整个 Python 生态。

## 8. 已知边界

- 转译是静态逐词替换，不做类型推断：同名方法在不同库中的中文名若冲突，已用不同词消歧（如 `正则分割` vs `分割`、`正则替换` vs `替换`）。
- 关键字 `在`/`从` 等只有在被识别为关键字语境时才会翻译；作为用户变量名的一部分（如 `现在`）不受影响（`现在` 不在关键字表中）。
- 用户自定义标识符若恰好与某个内置名相同（例如把函数命名为 `阶乘`），内置函数名优先，建议避免与内置名重名。
- 特殊字符串替换仅当字符串内容**完全等于** `__主__` 时生效。
